# Streamlit-Analytics-Hub
 A multipal -dashboard Streamlit suite for advanced statistical analysis

## 📂 Recommended Datasets

To fully test the capabilities of both dashboards, we recommend using datasets that contain a mix of continuous numbers, categorical text, and missing values (NaNs). 

If you download these from Kaggle, create a `Sample Datasets/` folder in your project directory and save them using the file paths below:

### 1. Rain in Australia ⛈️
A massive meteorological dataset with daily weather observations. Contains a significant amount of naturally missing data in columns like `Evaporation` and `Sunshine`.
* **Suggested File Path:** `Sample Datasets/weather_aus.csv`

### 2. Water Quality & Potability 💧
Highly numeric dataset measuring water safety metrics (pH, Sulfate, etc.) to predict potability. Excellent for multidimensional visualization.
* **Suggested File Path:** `Sample Datasets/water_potability.csv`

### 3. Loan Approval Prediction 🏦
Customer demographics and financial data used to determine loan eligibility. A perfect mix of categorical (Education, Property Area) and numerical (Income, Loan Amount) data.
* **Suggested File Path:** `Sample Datasets/loan_prediction.csv`

### 4. Heart Failure Clinical Records 🫀
Medical records featuring clinical features like blood pressure and serum sodium.
* **Suggested File Path:** `Sample Datasets/heart_failure.csv`

> **Note:** Due to size limits, these datasets might not be included in the repository. You can easily download them from Kaggle and place them in your `Sample Datasets/` folder to start exploring!
